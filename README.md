# Supply Chain Exception Agent

帮电商运营团队批量识别延迟订单的原因，并给出处置建议。

## 业务问题

电商履约链路（下单 → 库存分配 → 拣货包装 → 发货 → 运输 → 签收 → 售后）每天都会产生一批延迟订单。运营人员要判断延迟原因（卖家备货慢、物流线路问题、偏远地区等），再决定怎么处理（催卖家、换物流、主动补偿客户）以及先处理哪些。人工逐单查看效率低，也容易漏掉高风险订单。

> 待补充：延迟订单对客户评分的影响（第一周 SQL 分析后填入）。

## 方案思路

- **SQL 负责计算**：延迟天数、延迟率，以及按卖家、地区、品类的延迟分布
- **AI 负责判断**：读客户评论和订单上下文，归因延迟原因，为高风险订单生成处置建议和优先级
- **评估**：人工标注样本订单，量化 AI 归因的准确率

## 数据

[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)：真实脱敏的多表电商数据，包含订单、商品、客户、卖家和评论。
